# claude-mods

A collection of Claude Code mods.

## Mods

| Mod | What it does |
| --- | --- |
| `prompt-enhancer` | Enhances prompts before they are sent. |

## Install

At the prompt of a terminal session:

```
/plugin install prompt-enhancer --marketplace christensen143/claude-mods
```

From a shell:

```
claude plugin install prompt-enhancer --marketplace christensen143/claude-mods
```

Answer `y` to add the marketplace, then pick a scope.
